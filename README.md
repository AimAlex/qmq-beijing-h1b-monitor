# QMQ 北京 H-1B 面签位监控

使用 Playwright 打开 `https://qmq.app/`，读取动态渲染后的“当前可预约面签位”，筛选：

- 城市：北京
- 签证类型：H-1B
- 日期：2026-11-01 至 2026-11-15（含首尾）
- 排除：官方紧急申请 / 紧急申请 / Emergency Request

GitHub Actions 每 10 分钟运行一次。命中时创建 GitHub Issue，并上传本次 JSON 结果作为运行产物。

## 安全

本仓库不需要、也不得保存任何美签账号、密码、密保答案或 QMQ 订单信息。监控只访问 QMQ 公开页面。

## 重要限制

QMQ 当前会要求无感人机验证以显示具体日期。脚本不会绕过 CAPTCHA 或其他反爬保护；如果 GitHub Actions 环境无法自动通过网站正常提供的无感验证，本次运行会标记为“验证阻止”，不会把历史成功记录误报为当前可预约位。

可在 Actions 页面手动运行 `QMQ slot monitor` 进行测试。
